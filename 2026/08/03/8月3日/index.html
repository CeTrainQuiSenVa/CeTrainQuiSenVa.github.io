assert()

满足assert()中的条件则不会报错，若不满足则会在此行提示。这一方面是将程序员脑中的边界条件显式地写出来，方便调试；另一方面是，若程序在前面出错（不一定是报错），则它会带着错误结果继续运行，最后报错行不一定是出错的根源，不好调试。通过assert()可快速确定错误地点。另外，使用

qsort()

函数原型如上。base指向排序数组首元素, nmemb是数组元素个数, size是每个元素的字符数（因为qsort会将数组指针强制转换成void*类型, 所以它不知道数组元素的大小, 需要用户提供），compar即用户需要传入的比较函数指针。

这里和之前的函数指针也对应上了。注意qsort()函数指针要求是，如果a排在b前面，则函数应该返回负数，反之返回正数，0表示相等。

比较函数规则

qsort()非常灵活，因为比较的规则由程序员编写，所以它不仅可以按数值大小升序或降序排列，还可以按结构体成员大小或字典顺序排列。

函数元素的比较

注意到上面使用了两种方式，一种是用元素的指针访问，一种是直接访问元素本身。

比如最开始比较数组数字大小时传入的就是arr_asc(type == int *)，其元素为int，所以可以使用int *也可以使用*(int *)。之后的字符指针数组，因为比较的元素是字符串，所以可以使用char **也可以使用char *。（因为指针数组首地址，也就是指向指针的指针，又或者字符串本身（字符指针）都是指针，所以不需要用*解引用。
